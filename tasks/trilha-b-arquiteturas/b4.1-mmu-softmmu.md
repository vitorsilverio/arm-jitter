# B4.1 — MMU/softmmu para full-system (Linux 32-bit) **[REFINAR + RFC própria]**

**Trilha:** B · **Depende de:** B3; runner B4.0 recomendado antes · **Repo:** arm-jitter + hospedeiro novo
**Status de spec:** alto nível. Antes de implementar, escrever `docs/RFC-SOFTMMU.md`
(mesmo processo do B0) e aprovar com o usuário.

## Contexto

Para bootar um kernel Linux 32-bit é preciso emular a VMSA (MMU do ARM): tradução por
page tables, aborts precisos e CP15 completo. Hoje o `AddressSpace` é físico/flat e o
`BlockCache` é indexado por endereço físico=virtual.

## Questões que a RFC deve resolver

1. **Onde vive a tradução:** wrapper `TranslatingAddressSpace` (host chama com VA,
   wrapper resolve PA via TLB emulado + page walk) vs tradução dentro do JIT (inline
   TLB lookup no bytecode — mais rápido, muito mais complexo). Recomendação inicial:
   wrapper primeiro, inline depois com dado de profiling.
2. **Aborts precisos:** data abort/prefetch abort precisam interromper a instrução no
   meio (load não pode ter efeito parcial) e preencher FSR/FAR. Como o pipeline de
   executores/blocos JIT aborta uma op no meio? (provável: exceção Java dedicada
   capturada pelo runtime, que faz a entrada de exceção do core).
3. **BlockCache por contexto:** com MMU, o mesmo VA mapeia coisas diferentes por
   processo → chave do bloco precisa de ASID/geração de TLB, e trocas de TTBR/ASID
   invalidam/particionam o cache.
4. **CP15:** hoje `CoprocessorBus` delega ao hospedeiro. MMU exige acoplamento forte
   (TTBR, DACR, TLB ops, cache ops como NOP) — decidir o quanto de CP15 migra para
   dentro do arm-jitter (proposta: um `Cp15VmsaCoprocessor` opcional na lib).
5. **Interrupções/timers/UART/GIC:** ficam 100% no hospedeiro novo (linha IRQ/FIQ já
   existe no core). Definir o hospedeiro de referência (máquina tipo versatilepb ou
   virt-32, a decidir pelo suporte do kernel mainline).

## Aceite (do épico)

- Kernel Linux ARMv6/v7 mínimo (defconfig reduzida, initramfs busybox) boota até o
  shell no hospedeiro de referência.
- gbaemu/ndsemu intactos (nada disso é ativado nos caminhos deles — G3/G5).
