# B16.16 — MVE "long shift" sobre registradores de propósito geral (19 encodings, `t32.decode`)

**Trilha:** B · **Repo:** arm-jitter (+ revalidação G5) · **Depende de:** B16.15 (🟡, só para o contexto), B16.1 (✅)
**Épico:** `b16-plano-mve-helium.md` (reaberto) · **Status:** ⬜ spec escrita 2026-09-25

## Contexto

A B16.14 expôs 34 células `❌` fora do grupo `mve.decode`; a B16.15 fechou 22 delas e deixou as
**19 do "MVE long shift"** com destino nomeado (`B16.16`, esta task). É a maior fatia restante da coluna
`ARMv8.1-M+MVE` (26 células sobram; as outras 7 são `SB`/`CRC32*`, task `B22.8`).

Estruturalmente é **diferente do resto do MVE**: não toca `Q0`-`Q7` nem `VPR`. São shifts/saturações
sobre **registradores de propósito geral** — 32 bits (`Rda`) ou 64 bits (par `RdaLo:RdaHi`). Vivem no
espaço de bits do *Data-processing (shifted register)* (`1110 1010 0101 ...`), **em cima de `MOV`/`ORR`
com `Rm` ∈ {13,15}** (casos UNPREDICTABLE para `MOVS`/`ORRS`).

### As 19 formas (de `target/isa-decode/t32.decode`, linhas ~93-131; medir número de linha atual)

Imediato (11):

| 32 bits (`Rda`, `@mve_sh_ri`) | 64 bits (`RdaLo:RdaHi`, `@mve_shl_ri`) |
|---|---|
| `UQSHL_ri` (sat) | `LSLL_ri` · `UQSHLL_ri` (sat) |
| `URSHR_ri` | `LSRL_ri` · `URSHRL_ri` |
| `SRSHR_ri` | `ASRL_ri` · `SRSHRL_ri` |
| `SQSHL_ri` (sat) | `SQSHLL_ri` (sat) |

Registrador (8): 32 bits `UQRSHL_rr`, `SQRSHR_rr`; 64 bits `LSLL_rr`, `ASRL_rr`, `UQRSHLL64_rr`,
`SQRSHRL64_rr`, `UQRSHLL48_rr`, `SQRSHRL48_rr`.

(11 + 8 = 19 ✓ — bate com a contagem da B16.14.)

## Objetivo

As 19 formas decodificam e executam sob `ArmArchitecture.ARMV8_1M_MVE` (gate `MVE_INTEGER` + perfil M
mainline) com o resultado e o `APSR.Q` idênticos ao QEMU; a coluna `ARMv8.1-M+MVE` de
`docs/COBERTURA-ISA.md` ganha **+19 células `✅`** (96% → ~98,6%, 735/742), sem `⚠️` novo em nenhuma
coluna, e `MOV`/`ORR`/`MOVS`/`ORRS` de sempre continuam corretos em todos os presets.

## Semântica (LIDA do QEMU em `target/qemu-src`, `translate.c` ~2725-2965 e `mve_helper.c` ~2443-2570 —
## re-confirmar por `curl`/`grep`, não pelo resumo abaixo; ver [[feedback-curl-verbatim-qemu-source]])

**Gate comum** (`do_mve_shl_ri`/`_rr`/`sh_ri`/`sh_rr`), na ordem:

1. Sem `ARM_FEATURE_V8_1M` → `return false` (cai em `MOV`/`ORR`; UNPREDICTABLE lá).
2. **Formas de 64 bits com `rdahi == 15`** → `return false`: é a codificação de 32 bits (`SQSHL`/`SRSHR`/
   `UQSHL`/`URSHR`). Isto é a desambiguação entre as duas famílias — decodificar a de 64 bits primeiro.
3. Sem MVE, sem M-mainline, ou registrador proibido → **UNDEFINED** (escolha do QEMU para os casos
   UNPREDICTABLE). Proibidos por família:
   - 64 bits imediato: `rdahi == 13`.
   - 64 bits registrador: `rdahi == 13`, `rm == 13`, `rm == 15`, `rm == rdahi`, `rm == rdalo`.
   - 32 bits imediato: `rda ∈ {13,15}`.
   - 32 bits registrador: `rda ∈ {13,15}`, `rm ∈ {13,15}`, `rm == rda`.
4. Imediato: `shim == 0` significa **32** (`shim = imm5_12_6`, campo de 5 bits em `12:14 | 6:7`).
5. 64 bits: `rda = concat(rdalo, rdahi)` (lo em `[31:0]`); resultado volta `extrl`→`rdalo`, `extrh`→`rdahi`.
   `rdalo = 2*bits[19:17]`, `rdahi = 2*bits[11:9]+1` (`%rdalo_17`/`%rdahi_9` — ler as definições no
   `.decode`, **não** deduzir).
6. Registrador: só o **byte baixo de `Rm`**, **com sinal** (`(int8_t)`), é a quantidade; positivo = esquerda,
   negativo = direita.

**Operações** (helpers do QEMU, todas em `mve_helper.c`; `do_sqrshl_d`/`do_uqrshl_d`/`do_*_bhs` vêm de
`vec_internal.h`/`vec_helper.c` — baixar por `curl` e ler, não parafrasear):

| Forma | Operação | Seta `APSR.Q` |
|---|---|---|
| `LSLL_ri`/`LSRL_ri`/`ASRL_ri` | shift 64 puro (`shli`/`shri`/`sari`) | não |
| `SRSHRL_ri`/`URSHRL_ri` | `gen_srshr64_i64`/`gen_urshr64_i64` (round-shift-right) | não |
| `SQSHLL_ri`/`UQSHLL_ri` | `do_sqrshl_d`/`do_uqrshl_d`, shift +imm, sem round | **sim** (`&env->QF`) |
| `URSHR_ri`/`SRSHR_ri` | `gen_urshr32_i32`/`gen_srshr32_i32` | não |
| `SQSHL_ri`/`UQSHL_ri` | `do_*_bhs`, 32 bits, sem round | **sim** |
| `LSLL_rr` (`mve_ushll`) / `ASRL_rr` (`mve_sshrl`) | `do_uqrshl_d(n,(int8)s,false,NULL)` / `do_sqrshl_d(n,-(int8)s,false,NULL)` | **não** (`sat=NULL`) |
| `UQRSHLL64_rr`/`SQRSHRL64_rr` | `do_*_d(..., round=true, &QF)` (`SQRSHRL` nega o shift) | **sim** |
| `UQRSHLL48_rr`/`SQRSHRL48_rr` | `do_uqrshl48_d`/`do_sqrshl48_d` — **satura em 48 bits** (valor máx. `MAKE_64BIT_MASK(0,48)` sem sinal; `0x7FFF_FFFF_FFFF`/`0xFFFF_8000_0000_0000` com sinal) | **sim** |
| `UQRSHL_rr`/`SQRSHR_rr` | `do_*_bhs(..., 32, round=true, &QF)` (`SQRSHR` nega) | **sim** |

⚠️ **`QF` aqui é `APSR.Q`** (`CpsrRegister#setSaturation`), **não** `FPSCR.QC` — o resto do MVE vetorial
satura em `QC`. Não misturar. `Q` é sticky (só seta, nunca limpa).

## Inclui

1. Decoder das 19 formas — **novo** `Thumb2MveLongShiftDecoder` (ou extensão do decoder que hoje
   reivindica o `0xEA` de *shifted register* — **medir qual é**), registrado ANTES do `MOV`/`ORR`
   genérico. Cuidado de ordem idêntico ao da B13.22/B16.15 (`CLRM`×`LDM`), e a lição do
   `tasks/FILA-EXECUCAO.md`: `Thumb2NocpDecoder` (B15.2) reivindica todo o espaço MVE sob `M_PROFILE`.

   `saturating`, `round`, `bits`(32/48/64) e origem da quantidade (imediato vs `Rm`). `Kind` novo(s) em
   `InstructionKind` (Kinds após 187), com `supportsCoherence` correspondente nos 3 backends
   (INTERPRETED executa; ASM/Truffle recusam ou caem em fallback — mesmo padrão do resto do MVE).
3. Executor em `IrSystemExecutor`/`IrBlockExecutor` lendo/escrevendo GPRs e `APSR.Q`.
4. **Reuso**, não duplicação: as primitivas `sqrshl`/`uqrshl` de 64 bits e o round-shift já existem em
   `advsimd.AdvSimdLanes` (B8/B13, `shiftByRegister`/`sqrshl`); medir se cobrem 64 bits e o corte de 48
   antes de escrever um utilitário novo. O corte de 48 bits é o único trecho sem precedente.
5. Rejeição UNDEFINED dos registradores proibidos (item 3 do gate) — **UNDEF, nunca silenciar** (G8).
6. Regenerar `docs/COBERTURA-ISA.md`/`docs/COBERTURA-JIT.md` (exige `mvn install` do core antes — o gerador
   lê o jar do `~/.m2`); delta registrado.

## Armadilhas

1. **`rdahi==15` é outra instrução**, não erro — testar a desambiguação nos dois sentidos.
2. **`APSR.Q` ≠ `FPSCR.QC`.** E `LSLL_rr`/`ASRL_rr` passam `sat=NULL`: não tocam `Q`.
3. **`SQRSHR*` negam a quantidade** (`-(int8)shift`); `LSLL_rr` não.
4. **`(int8_t)` do byte baixo de `Rm`** — `Rm=0x0000_0180` é shift 0x80 = −128, não +384.
5. **`shim=0` → 32** só no imediato; no registrador shift 0 é 0.
6. **48 bits** têm limites próprios (não os de 64): o `shift <= -48` do `sqrshl48` devolve `src>>63`
   (com round, 0), e `>= 48` só satura se `src != 0`.
7. **Ordem de decoder** (`Thumb2NocpDecoder` já reivindica o espaço MVE sob M; `MOV`/`ORR` reivindicam o
   resto). Lição B13.22: medir por JaCoCo que o ramo novo é de fato alcançado.
8. **Não deduzir de nome/manual de cabeça** — ler o QEMU; divergências de manual vs QEMU vão em `## Resultado`.
